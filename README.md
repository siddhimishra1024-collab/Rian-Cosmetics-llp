# Rian-Cosmetics-llp
# Form Project

## About the Project
This project is a form-based web application built using HTML, CSS, and JavaScript. It was developed to practice frontend development and understand how to create interactive forms.

## Technologies Used
- HTML5 — Structure of the form
- CSS3 — Styling and layout
- JavaScript — Form interactivity and client-side validation (if implemented)

## Features
- User-friendly form interface
- Input fields for collecting user information
- Interactive functionality using JavaScript

## Current Limitations
- No backend integration
- No database connectivity
- Form data is not permanently stored on a server

## How to Run
1. Download or clone this repository.
2. Open `Rian_Cosmetics_llp.html` in your web browser.
3. Interact with the form.

## Future Improvements
- Add backend integration
- Connect a database for data storage
- Implement secure form submission and server-side validation
